# Contributing to Geregeld

Geregeld is a source-available product maintained by Daniel Agg.

## Bug reports and suggestions

Bug reports and feature suggestions are welcome through GitHub Issues.

Before opening an issue:

- Check whether a similar issue already exists.
- Include steps that reproduce the bug and the result you expected.
- Remove personal, confidential, and client information.
- Do not report security vulnerabilities in a public issue.

## Pull requests

We do not currently accept unsolicited pull requests.

Geregeld is offered under noncommercial and commercial terms, so each
contribution needs a documented chain of rights.

Please open an issue or contact daniel.agg@outlook.com before beginning work on a code contribution.

If we invite you to contribute, we may require a separate Contributor License
Agreement. The agreement allows Daniel Agg to use and license the contribution
under noncommercial and commercial terms.

Submitting a pull request without prior agreement does not guarantee that it will be reviewed or accepted.

## Security vulnerabilities

Do not disclose suspected security vulnerabilities through public issues.

Report them through GitHub's private vulnerability reporting feature or email
danielagg@outlook.com.

Include:

- A description of the vulnerability.
- Steps to reproduce it.
- Its potential impact.
- Any suggested mitigation.

We will acknowledge the report as soon as reasonably possible.
