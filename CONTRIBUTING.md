# Contributing to Geregeld

Thank you for your interest in Geregeld.

Geregeld is a source-available, commercially licensed product maintained by Daniel Agg.

## Bug reports and suggestions

Bug reports and feature suggestions are welcome through GitHub Issues.

Before opening an issue:

- check whether a similar issue already exists;
- include clear steps for reproducing bugs;
- describe the result you expected;
- remove personal, confidential and customer information; and
- do not publicly report security vulnerabilities.

## Pull requests

We are not currently accepting unsolicited pull requests.

Because Geregeld is offered under both noncommercial and commercial terms, we need to maintain a clear and documented chain of rights for every contribution.

Please open an issue or contact daniel.agg@outlook.com before beginning work on a code contribution.

If we invite you to contribute, you may be required to sign a separate Contributor License Agreement before your contribution can be accepted. That agreement will allow Daniel Agg to use and license the contribution under both noncommercial and commercial terms.

Submitting a pull request without prior agreement does not guarantee that it will be reviewed or accepted.

## Security vulnerabilities

Do not disclose suspected security vulnerabilities through public issues.

Report them privately using GitHub’s private vulnerability reporting feature or email daniel.agg@outlook.com.

Include:

- a description of the vulnerability;
- steps to reproduce it;
- its potential impact; and
- any suggested mitigation.

We will acknowledge receipt as soon as reasonably possible.
